# MoRentHub - แพลตฟอร์มปล่อยเช่ารถและบ้าน (TypeScript, React, Node.js & Docker)

เว็บแอปพลิเคชันสำหรับปล่อยเช่ารถและบ้านพัก/คอนโด พร้อมระบบแผนที่นำทางด้วย Google Maps ระบบจัดการสำหรับแอดมิน และรองรับการแสดงผล Responsive บนทุกอุปกรณ์ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

🎨 **ธีมการออกแบบ:** สไตล์โมเดิร์น โทนสีชมพูพาสเทล (`#FBCFE8`), ฟ้าพาสเทล (`#BAE6FD`) และสีขาวสะอาดตา

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. หน้าสำหรับผู้เข้าชมทั่วไป (ไม่ต้องเข้าสู่ระบบ)
- **หน้าแรก (Home Catalog):**
  - แสดงการ์ดรายการ (ภาพปก, ชื่อบ้าน/รถ, สถานะความพร้อม, สถานที่ตั้ง, ราคา)
  - ตัวกรองแยกหมวดหมู่ (บ้าน/คอนโด vs รถยนต์)
  - ตัวกรองสถานะ (ว่างให้เช่า vs มีผู้เช่าแล้ว)
  - ค้นหาด้วยคีย์เวิร์ดแบบ Real-time
- **หน้ารายละเอียดรายการ (Listing Details):**
  - แกลเลอรีรูปภาพหลายมุมมอง
  - รายละเอียดและเงื่อนไขการเช่า ราคา และหน่วยเวลา (ต่อวัน / ต่อเดือน / ต่อปี)
  - **ระยะเวลาการเช่า:** แสดงวันที่เริ่มต้นเช่าถึงวันที่สิ้นสุดสัญญา (อัปเดตโดยแอดมิน)
  - **แผนที่และระบบนำทาง (Interactive Map & Google Maps Navigation):**
    - แสดงหมุดและแผนที่พิกัดจริงของบ้านพักหรือรถยนต์
    - ปุ่มเปิดการนำทางตรงไปยัง Google Maps เพื่อคำนวณเส้นทางถนนจริงและสภาพการจราจรแบบเรียลไทม์
  - **ช่องทางการติดต่อ:** มีเบอร์โทรศัพท์ (กดโทรออกได้ทันที), บัญชี LINE, และ Facebook ของแอดมินโดยตรง เพื่อความปลอดภัยและป้องกันการหลอกลวง

### 2. หน้าสำหรับผู้ดูแลระบบ (Admin)
- **ระบบเข้าสู่ระบบปลอดภัย (Secure Login):**
  - มีรหัสภาพสุ่ม (CAPTCHA) ป้องกันบอททุกครั้ง
  - บัญชีเริ่มต้น: `admin` / `adminmo2026` (รหัสผ่านเข้ารหัสด้วย bcrypt)
- **หน้าจัดการข้อมูล (Admin Dashboard):**
  - ตารางสรุปภาพรวม KPI (จำนวนบ้าน, จำนวนรถ, จำนวนที่ว่าง, จำนวนที่มีผู้เช่า)
  - เพิ่มรายการใหม่ พร้อมอัปโหลดรูปภาพได้จากเครื่อง หรือวาง URL รูปภาพ
  - แก้ไขข้อมูลรายการแบบสมบูรณ์
  - **อัปเดตสถานะด่วน:** เปลี่ยนสถานะ (ว่าง / มีผู้เช่าแล้ว) และกำหนดวันที่เริ่ม-สิ้นสุดสัญญาเช่า
  - ลบรายการพร้อมระบบแจ้งเตือนยืนยัน
- **หน้าโปรไฟล์แอดมิน (Profile Management):**
  - สามารถเปลี่ยนชื่อผู้ใช้ (Username) และเปลี่ยนรหัสผ่านใหม่ได้ตลอดเวลา (ต้องยืนยันรหัสผ่านปัจจุบันก่อนเปลี่ยน)

## 🚀 วิธีการรันและทดสอบระบบ

### 1. รันด้วย Docker (One Command)
```bash
docker compose up --build
```
- เปิดเว็บที่: `http://localhost:3000`

### 2. รันแบบแยกโฟลเดอร์สำหรับ Development
```bash
# Terminal 1: Backend API
cd backend
npm run dev

# Terminal 2: Frontend Web
cd frontend
npm run dev
```
